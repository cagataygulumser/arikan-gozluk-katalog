# Arıkan Optik 2026 Gözlük Kataloğu — Görsel ve Veri Deposu

Bu depo, Arıkan Optik'in 2026 kataloglarındaki (Lee Cooper, Quantum, Slazenger, Belmond) gözlük modellerinin görsellerini ve yapılandırılmış verisini barındırır. Blogger sitesi bu depodan jsDelivr CDN üzerinden beslenir.

- `models.json` — tüm modeller (kod, ölçüler, malzeme, renk varyantları, görsel adları)
- `img/<marka>/<KOD>-on.jpg` / `-yan.jpg` — model kapak görselleri
- `img/<marka>/<KOD>-C<n>-on.jpg` / `-yan.jpg` / `-clip.jpg` — renk varyantı görselleri

CDN adresi: `https://cdn.jsdelivr.net/gh/cagataygulumser/arikan-gozluk-katalog@main/`
